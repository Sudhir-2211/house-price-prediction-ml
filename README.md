## 📖 Project Overview

Accurate property valuation is a classic predictive modeling problem with high non-linearity and complex multi-feature interactions (e.g. square footage interacts heavily with geographic location tier).

This repository provides:
- **Leakage-Free Preprocessing**: Encapsulated inside a scikit-learn `Pipeline` via `ColumnTransformer`, ensuring test data and future inference inputs are transformed strictly using parameters learned from training folds.
- **Multi-Model Benchmark**: Trains and evaluates linear regularized models alongside non-linear tree ensembles.
- **Uncertainty Quantification**: Accompanies point estimates with statistical 90% confidence bands.
- **Reproducible Workflow**: Automated data generation, training, serialization, evaluation, and interactive interfaces.

## 🛠️ Machine Learning Pipeline Architecture

```text

                   │
                   ▼
  ┌─────────────────────────────────────────────────────────────┐
  │                 ColumnTransformer Preprocessor               │
  │  ┌──────────────────────────────┐ ┌──────────────────────┐  │

  │  │ (sqft, beds, baths, etc.)    │ │ (location_tier)      │  │
  │  └──────────────────────────────┘ └──────────────────────┘  │
  └─────────────────────────────────────────────────────────────┘
                   │
                   ▼
  ┌─────────────────────────────────────────────────────────────┐
  │             GradientBoostingRegressor (Best Model)          │
  │             (150 Estimators, Learning Rate 0.08)            │
  └─────────────────────────────────────────────────────────────┘
                   │
                   ▼
  Predicted Property Value ($) + 90% Statistical Interval
```

## 📐 Feature Set & Engineering

| Feature Name | Type | Description / Range |
|---|---|---|
| `sqft_living` | Integer | Total interior finished living space (700 to 5,500 sq ft) |
| `bedrooms` | Integer | Number of full bedrooms (1 to 6) |
| `bathrooms` | Float | Number of bathrooms (1.0 to 5.0 in 0.5 increments) |
| `location_tier` | Categorical | Urban Prime, Suburban Central, Outer Suburban, Rural Scenic |
| `year_built` | Integer | Original construction year (1950 to 2024) |
| `lot_size_acres` | Float | Property parcel acreage (0.05 to 3.0 acres) |
| `garage_spaces` | Integer | Enclosed vehicle stalls (0 to 3) |
| `condition_rating` | Integer | Overall structural and interior condition score (1 to 5) |
| `has_pool` | Binary | Inground swimming pool present (0 = No, 1 = Yes) |
| **`price`** | Target | Continuous market transaction value in USD |

## 📊 Model Comparison & Benchmark Results

Evaluated on a held-out 20% test partition (500 properties) with random seed 42:

| Model Architecture | $R^2$ Score | Mean Absolute Error (MAE) | Root Mean Squared Error (RMSE) | Mean Absolute % Error (MAPE) |
|---|---|---|---|---|
| **Gradient Boosting** *(Selected)* | **0.9378** | **$37,465.02** | **$49,944.76** | **5.97%** |
| Ridge Regression (L2) | 0.9299 | $40,118.14 | $53,015.03 | 6.62% |
| Random Forest Regressor | 0.9182 | $42,531.39 | $57,297.78 | 6.80% |

**Winning Model**: Gradient Boosting achieved the highest $R^2$ (0.9378) and the lowest MAPE (5.97%), effectively capturing the non-linear interaction between square footage and premium urban location tiers.

## 🚀 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sudhir-2211/house-price-prediction-ml.git
   cd house-price-prediction-ml
   ```

2. **Set up virtual environment**:
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On Linux / macOS:
   source venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Retrain or verify model**:
   ```bash
   python -m src.train
   ```
